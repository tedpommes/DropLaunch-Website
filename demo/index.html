    Guided tour

    From nothing to a running Rust server

    Everything DropLaunch does on a real PC, in order. Steps tick off as they happen in the window: downloads, the server and Rust are simulated.

    0 of 16 done

    1One-click setup

    1. A Rust server needs two things from Valve: SteamCMD and the server files. One click gets both, plus a mod framework and the start files.

      Do itClick Set up a server on the welcome screen. Closed it? Fix it on the Maps page opens the same setup.

    2. Valve's command-line Steam client, the tool every Rust server is installed with. DropLaunch downloads it and lets it update itself on its first start.

      On your PCDropLaunch\SteamCMD\steamcmd.exe

      Do itNothing to click: it runs by itself once the setup starts.

    3. SteamCMD signs in anonymously and downloads Rust's dedicated server, about 6 GB. Only once: an update later gets just what changed.

      On your PCDropLaunch\Server_Files\RustDedicated.exe

      Do itNothing to click. On a real PC this is the long part, 5 to 30 minutes: Hide keeps it going while you look around.

    4. The mod framework that runs plugins. The RustEdit extension is for maps that use RustEdit features, and the DropLaunch plugin lets testers send bug reports with /bug.

      On your PCCopied into DropLaunch\Server_Files

      Do itPick one under Mods in the setup window while the server downloads. Carbon is the default.

    5. start_procgen_server.bat starts the server with DropLaunch's settings: ports, RCON and the map. update_server.bat runs SteamCMD to update it. Both work without DropLaunch too: double-click them.

      On your PCDropLaunch\Server_Files\start_procgen_server.bat update_server.bat

      Curious?See what goes in one with the start file generator.

    6. DropLaunch runs the start file. The server opens in its own console window, and DropLaunch reads its log to show how far it is.

      Do itWith Run test map server on, press Next, then Continue when the setup is done (with Continue when done ticked, it goes on by itself). Otherwise press play next to any map on the Maps page.

    2Your first server

    1. The server loads the game files, starts Carbon and generates the map. The first start takes a few minutes on a real PC; DropLaunch shows each stage.

      Do itWatch the bar at the bottom of the Maps page until it says Ready.

    2. Join starts Rust, or uses the one that's open, and connects you. Without DropLaunch it's F1 in Rust and client.connect 127.0.0.1:28015.

      Do itClick Join in Rust once the server is ready.

    3Test your own map

    1. Maps in DropLaunch's Maps folder show in the list by themselves. A .map file dropped on the window, or on DropLaunch.exe, starts straight away (a running server stops first), right where it is: a re-export is picked up on the next start.

      Do itDrag Canyon_Rally_v18.map from the Downloads folder onto the window.

    2. Two .bat files for that map: one starts it normally, one in prefab test mode for unfinished maps (no cargo ship, boat paths or events). Start the map without DropLaunch, or send them to a friend.

      On your PCServer_Files\start_Canyon_Rally_v18.bat start_Canyon_Rally_v18_prefab.bat

      Do itRight-click a map and choose Create start files.

    3. With the DropLaunch plugin, testers type /bug and a few words in Rust's chat. The report lands on a map of your island, where they stood. In the demo, testers join and send some on their own.

      Do itClick More options and open Bug reports once one has come in.

    4Run the server

    1. The console shows the server's log and sends commands over RCON. Try status to see who's online.

      Do itClick More options, type in the box under the console and press Enter.

    2. Hand a kit to anyone on your server, like the built-in Basic Build Kit, without typing item names in the console.

      Do itIn More options, open Give items, pick a kit and a player.

    3. Stop saves the world, then closes the server's window. Restart does the same and runs the start file again.

      Do itClick Stop in the server bar.

    4. When Rust updates, DropLaunch runs SteamCMD again, like update_server.bat does, and puts Carbon or Oxide back. The pill at the top says when a new build is out.

      Do itWith the server stopped, open Server files (in More options) and click Verify files. When there's a new build, Update shows next to it.

    5Make it yours

    1. DropLaunch takes more than maps: a .zip with a map and its start file, start files from the generator, kits, themes and language files. Each goes where it belongs, and Settings → Dropped assets lists what you dropped.

      Do itDrag another file from the Downloads folder onto the window, like Sunrise theme.json for new colours.

    That's all of it

    On your PC it's the same clicks, with real downloads. DropLaunch is free and open source, for Windows.
