Start file generator

A start file for a Rust server, for Windows or Linux: a procedural or custom map, RCON, prefab test mode, and a script that installs and updates the server with SteamCMD. They're the files DropLaunch writes, and it can do all of this for you. Or drop a file you make here on DropLaunch, and your maps start with its settings.
