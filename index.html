How it works

From a map file to playing on it

Three steps, and only the first time. After that it's drop a map and click ▶.

  1. Download and start it

    Put DropLaunch.exe in an empty folder, like C:\DropLaunch, and start it. It creates its folders next to itself.

  2. Set up a server

    One click downloads SteamCMD and the Rust server: about 6 GB, 5 to 30 minutes. Pick Carbon or Oxide and the RustEdit extension meanwhile.

  3. Drop a map and play

    Drop a .map or .zip on the window and click ▶. When it says Ready, Join in Rust takes you in.

Setup

Sets everything up for you

The first time, one click downloads SteamCMD and the Rust server. While it downloads you pick the rest, and Hide keeps it going in the background.

  • Carbon or Oxide, updated along with the server
  • The RustEdit extension, for maps that need it
  • Admin on every test server, with the Steam account it finds on your PC
  • Finds what you already have: SteamCMD and server files are reused, not downloaded again
Playtesting

Bug reports from your testers

Testers type /bug and a few words in Rust's chat. The report shows up on a map of your island, with where they stood and which way they looked. Teleport there to see it yourself.

Questions

Good to know

Windows says "Windows protected your PC"

Windows shows this for programs that aren't code-signed and that not many people have downloaded yet. Click More info, then Run anyway.

Every release is built from the source on GitHub, so you can check what it does.

My antivirus doesn't like it

Tools that download files and start servers sometimes get flagged by mistake. Please open an issue saying which antivirus, so it can be reported as a false positive.

What do I need?

Windows 10 or 11 (64-bit), about 7 GB of free disk space for the Rust server, and Rust on Steam to join your server. No installer, no .NET, no other downloads.

How do I update?

DropLaunch tells you when a new version is out and what changed, and one click updates it. Every update is signed with the author's key: DropLaunch refuses a download that doesn't match.

Does it collect anything about me?

No. DropLaunch has no accounts, no analytics and no telemetry. Its settings, maps, kits, bug reports and log stay on your PC.

On its own it only looks for updates on GitHub and loads the Rust server's branch list. Everything else, like downloading the server, happens when you ask for it. All the details.

Something doesn't work

Please open an issue or ask on Discord, and attach droplaunch.log from %LOCALAPPDATA%\DropLaunch: DropLaunch writes what went wrong there.

Is it really free?

Yes. DropLaunch is free software under the GNU General Public License v3.0: free to use, share and change.

How do I remove it?

Stop any running server, then delete the DropLaunch folder. Its settings, kits and bug reports are in %LOCALAPPDATA%\DropLaunch: delete that folder too.
